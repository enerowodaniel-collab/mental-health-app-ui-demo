# mental-health-app-ui-demo
This is a React Native demo app showcasing clean, minimal, and modern mobile UI screens for a driving app. It includes:

Onboarding screen with illustration, headline, subtitle, and call-to-action button

Login screen with email/password fields and a login button

Home/Dashboard screen with example stats, cards, and bottom navigation

All screens are UI-only, fully styled, and ready to run in Expo Go.
The project is intended to demonstrate mobile UI design skills and is ideal for portfolio presentation. Screenshots and an optional demo video show the app in action.
